# Painel de treino

Painel pessoal de treino e dieta. **O conteúdo é privado**: a página é criptografada (AES-256-GCM, chave derivada da senha com PBKDF2-SHA256, 600 mil iterações) e só abre com a senha. Sem ela, o arquivo `index.html` deste repositório é ilegível.

Registros, pesos e fotos ficam salvos só no navegador de cada aparelho, nunca neste repositório.

## Créditos

- Modelo anatômico: **BodyParts3D**, © The Database Center for Life Science (DBCLS), licença [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Geometria simplificada e convertida para este site; reto abdominal e latíssimo do dorso reconstruídos a partir da pele do mesmo modelo. Dados processados a partir do projeto [human-atlas](https://github.com/ashemag/human-atlas).
- Renderização 3D: [three.js](https://threejs.org) (MIT).
- Fontes: Big Shoulders Display e Atkinson Hyperlegible (SIL Open Font License).
